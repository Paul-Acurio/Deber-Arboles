# Árbol BST Empresarial en C++

## Integrante
- Paul Acurio
## Objetivo
Implementar en C++ un Árbol Binario de Búsqueda (BST) para organizar a los empleados de una empresa utilizando un código numérico como clave de jerarquía.

## Funcionalidades
- **Insertar empleados:** Añade un nuevo registro respetando la propiedad del BST (menores a la izquierda, mayores a la derecha).
- **Buscar empleados:** Permite localizar a un empleado específico mediante su código.
- **Mostrar raíz:** Identifica el nodo superior de la jerarquía (Ej: Empresa UTA).
- **Recorridos:** Muestra la estructura en inorden, preorden y postorden.
- **Calcular altura:** Determina la longitud máxima desde la raíz hasta la hoja más profunda.
- **Mostrar nodos hoja:** Lista los empleados que no tienen subordinados (nodos sin hijos).

## Conclusión
La implementación de un Árbol Binario de Búsqueda nos permite organizar información jerárquica de manera lógica. Al basar la estructura en códigos numéricos, logramos realizar operaciones de búsqueda, inserción y lectura de datos de manera mucho más eficiente que en una estructura lineal.
